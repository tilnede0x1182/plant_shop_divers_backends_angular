# 7
Analyse des fichiers restants à implémenter :
- `utils/JsonMapper.java` : doit offrir une sérialisation JSON sans dépendre de Jackson (comme dans Javalin). S’appuyer sur org.json (déjà utilisé dans gateway) pour convertir Map/Collection/POJO en JSON string.
- `order-service/src/services/PlantLookup.java` : wrapper réutilisé par `ApiMapper.toOrderItems`. Nécessite un accès à `PlantRepository` et une méthode `find(int id)` qui lève une Exception si besoin. On peut simplement injecter le repo dans le constructeur.
- `gateway/src/core/RouteTarget.java` : record/POJO déterminant la cible en fonction de l’URL (`/auth`, `/plants`, `/orders`, `/users`). Même logique que dans la classe `Routes` du projet distribué.
- `gateway/src/core/SessionContext.java` : record porteur de trois champs (auth flag, userId, admin). Doit offrir une méthode `anonymous()` pour les cas non authentifiés.
- `gateway/src/core/GatewayHandler.java` : logique principale du proxy HTTP (copier celle de `Routes.java` distribué). Paramètres requis : config (URLs services), HttpClient, Session resolver (utilisant `Request.extractSessionId`). Assurer la propagation des cookies et des headers `X-User-*`.
