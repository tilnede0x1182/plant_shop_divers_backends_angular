RÉSUMÉ DES PATTERNS
================================================================================

TOUS LES PROJETS:
- Variables ROOT, LIB_DIR, UTILS_DIR, *_DIR pour chaque service
- compile-utils, compile-auth, compile-catalog, compile-order, compile-user, compile-gateway
- run-auth, run-catalog, run-order, run-user, run-gateway
- pm2-start-all, pm2-stop-all
- clean modifié pour tous les bin
- seed-dev, test-dev, build-dev conservés

DISTRIBUÉE (5 projets):
- DB unique: db/schema.sql, db/Seed.java
- db-migrate, seed, db-seed, db-reset standards

MICROSERVICES (5 projets):
- DB par service: service-name/db/schema.sql, service-name/db/Seed.java
- db-migrate-auth, db-migrate-catalog, db-migrate-order, db-migrate-user
- db-migrate: appelle toutes les migrations
- compile-seed-auth, compile-seed-catalog, compile-seed-order, compile-seed-user
- seed-auth, seed-catalog, seed-order, seed-user
- seed: appelle tous les seeds
- db-reset: db-drop db-create db-migrate seed

SPÉCIFICITÉS PAR FRAMEWORK:
- Spring Boot: flags -J-Dorg.jboss.logging.provider=jul, InstallCoursier.java
- Micronaut: InstallCoursier.java, flags spécifiques framework
- Quarkus: InstallCoursier.java, META-INF si nécessaire
- Javalin: InstallLibs.java (libs.yaml), ApplicationController.java dans chaque service
